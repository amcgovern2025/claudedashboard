# Deployment Guide — SynthSeg Brain Metrics Dashboard

## What you need

| File | Source |
|---|---|
| `brain_metrics_summary.csv` | Output of `python run_brain_metrics.py volumes.csv` |
| `brain_metrics_plot.png` | Same command (saved alongside the CSV) |
| `index.html` + `css/` + `js/` | Already in this repo |

---

## 1. Generate your results

Run the pipeline on your SynthSeg output (see `synthseg_pipeline.ipynb` for the
full Colab workflow):

```bash
# Local — Python 3.11+, numpy<2, tensorflow==2.15
pip install tensorflow==2.15.0 "numpy>=1.24,<2" nibabel scipy pandas matplotlib h5py

python run_brain_metrics.py path/to/volumes.csv --output-dir .
```

This writes two files to the current directory:
- `brain_metrics_summary.csv`
- `brain_metrics_plot.png`

**From Colab**, use the cells at the bottom of `synthseg_pipeline.ipynb`
(`brain_metrics` module cells) and download the two files.

---

## 2. Deploy to GitHub Pages

### Step A — Enable GitHub Pages (one-time)

1. Go to your repo on GitHub.
2. **Settings → Pages → Source** → select **Deploy from a branch**.
3. Choose **branch: `master`** (or `main`) and **folder: `/ (root)`**.
4. Click **Save**. Your site will be live at:
   `https://<your-username>.github.io/<repo-name>/`

### Step B — Commit your results files

```bash
# Copy the two output files into the repo root
cp /path/to/brain_metrics_summary.csv .
cp /path/to/brain_metrics_plot.png    .

git add brain_metrics_summary.csv brain_metrics_plot.png
git commit -m "Update brain metrics results"
git push origin master
```

GitHub Pages re-deploys automatically within ~1 minute.

### Step C — Visit the dashboard

Open `https://<your-username>.github.io/<repo-name>/` — the dashboard section
on the page will auto-fetch `brain_metrics_summary.csv` and
`brain_metrics_plot.png` and render:

- **Metric cards** — ICV, hippocampus, amygdala, thalamus, cortex, WM,
  lateral ventricles, brainstem (raw cm³ + % ICV)
- **Summary plot** — 3-panel matplotlib figure (raw volumes, ICV-normalised,
  hemispheric asymmetry)
- **Sortable table** — all regional volumes

## 3. Multi-subject / longitudinal use

The `brain_metrics_summary.csv` can contain multiple subjects.
`run_brain_metrics.py` accepts a single `volumes.csv`; to combine subjects,
concatenate their CSVs:

```python
import pandas as pd, glob

dfs = [pd.read_csv(f) for f in glob.glob("sub-*/volumes.csv")]
combined = pd.concat(dfs, ignore_index=True)
combined.to_csv("volumes_all.csv", index=False)
```

Then run the pipeline on the combined file:

```bash
python run_brain_metrics.py volumes_all.csv --output-dir .
```

The dashboard will show a **Subject** dropdown to switch between subjects.

## 4. Local preview (without a server)

Opening `index.html` directly via `file://` blocks `fetch()` due to browser
security restrictions, so the CSV will not auto-load. Two options:

### Option A — Python local server (recommended)
```bash
cd /path/to/repo
python -m http.server 8080
# Open http://localhost:8080
```

### Option B — VS Code Live Server extension
Install the **Live Server** extension, right-click `index.html` → **Open with
Live Server**.

### Option C — Upload manually
Open `index.html` in any browser, then use the **Upload CSV** / **Upload Plot**
buttons in the dashboard section to load your local files directly — no server
needed.

---

## 5. Updating results for a new scan

1. Re-run `python run_brain_metrics.py new_volumes.csv --output-dir .`
2. Commit and push the two updated files.
3. GitHub Pages auto-deploys. No other changes needed.

---

## 6. Troubleshooting

| Symptom | Fix |
|---|---|
| Dashboard shows "DEMO" banner | CSV not fetched — either not committed yet, or using `file://`. See §4. |
| Plot not showing | `brain_metrics_plot.png` not committed. Upload manually via the Plot button. |
| Wrong columns in table | CSV was generated by an older version. Re-run `run_brain_metrics.py`. |
| ICV shown as `—` | SynthSeg didn't output an ICV column. Re-run SynthSeg with `--vol` flag or check column names in the CSV. |
| Blank cards for some ROIs | SynthSeg label naming differs — add a pattern to `brain_metrics/regions.py` and re-run. |
